# Hobby Images

Place hobby photos here. Expected filenames:

- `hobby-1.jpg` — Reading
- `hobby-2.jpg` — Open Source
- `hobby-3.jpg` — UI/UX Design

**Requirements:**
- 4:5 portrait aspect ratio recommended (e.g. 800×1000px)
- JPG or WebP format

The portfolio uses styled gradient placeholders as fallback if these files are missing (no 404 errors).
